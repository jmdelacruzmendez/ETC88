## 4. PALETA — alinear con el sistema ΙΧΘΥΣ

El sistema visual oficial usa **los 5 colores de las letras del pez**:
- Ι (iota) = **celeste** `#B7E9EC`
- Χ (ji) = **rojo** `#DA1F22`
- Θ (theta) = **azul** `#1E2BB6`
- Υ (ípsilon) = **naranja** `#F0871F`
- Ϲ (sigma) = **magenta** `#D21C82`

Base sobria: **crema** `#F7F1E3` (papel) · **marrón** `#4E3119` (texto, filetes, titulares) · **dorado** `#E9C44E` (pez, acentos cálidos).

### Cambio principal
**Guías = celeste (Ι)**, no verde. Hoy usas verde, que **no está en el sistema** y se siente más "scout/excursionista" que ETC.

### Asignación recomendada
- Guías = **celeste (Ι)** — cambia
- Cocina = **azul (Θ)** — ya estaba cerca
- Música = **naranja (Υ)** — ya está
- Asesores del retiro = **rojo (Χ)**
- Cierre / Asesores espirituales / Dirección = **magenta (Ϲ)** o **dorado**

### Íconos de número de sección — sin patrón hoy
Hoy los números de §1–§12 usan colores aleatorios (azul, verde, rojo, naranja). **Recomendación:** todos los números de sección en **marrón uniforme** y reservar los 5 colores ΙΧΘΥΣ solo para áreas (§3 Roles) y anexos. El color tiene que decir algo; hoy es ornamental.
