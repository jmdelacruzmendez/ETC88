# Mi recomendación de portada — ETC 88

> Análisis de la portada actual + tres direcciones nuevas con sus tradeoffs + recomendación final.

---

## 1. La portada actual — qué funciona y qué no

### Lo que funciona ✅
- Pez ICTUS amarillo con las 5 letras de colores como elemento central — eso es **el** símbolo, está bien que esté.
- Lema del retiro completo + cita Mt 6,21 ✅.
- Fecha al pie sin lugar ✅.
- "ENCUENTRO TOTAL CON CRISTO" como eyebrow — ubica al lector.

### Lo que NO termina de funcionar
1. **Demasiados elementos** apilados verticalmente — eyebrow + ETC + 88 + subtítulo + pez + lema + cita + lema eteciano + 2 corazones + fecha = **9 capas**. Una portada respira con 4-5, no con 9.
2. **El "ETC 88" en azul + rojo es duro** — son colores planos sin transición. El rojo del 88 se siente "rojo navidad" sin atmósfera (no es ni el rojo ΙΧΘΥΣ ni el dorado del pez).
3. **Los corazones marrón + negro** — el negro está desconectado de toda la paleta. Si dos corazones, deberían ser **marrón + dorado** o **dorado + dorado oscuro** para coherencia.
4. **El pez es mediano**, no héroe — debería ocupar más espacio relativo y dominar la composición. Hoy compite con el 88.
5. **"Siempre amigos" en la portada es ruido** — es el lema eteciano (institucional), no del retiro. Esa info pertenece a la portadilla interior o a la contracubierta. La portada debe respirar UN solo lema: el del retiro.
6. **Ningún borde, marco, o anclaje visual** — la portada flota en crema sin estructura. Falta un detalle que diga "esto es un libro impreso, no una hoja A4".
7. **La fecha en mayúsculas sutil al pie** se siente como "metadata" — debería tener más personalidad.

## 2. Tres direcciones nuevas — con tradeoffs

### 🅰 Opción A — "Editorial sobria"

**Concepto:** el pez como **héroe absoluto** centrado, el "88" como número discreto, el lema como eje espiritual. Estilo de libro impreso clásico.

```
┌─────────────────────────────────────┐
│                                     │
│   ─── ENCUENTRO TOTAL CON CRISTO ───  │   ← eyebrow small caps, marrón
│                                     │
│              LXXXVIII               │   ← romano grande, sobre el pez
│                                     │
│                                     │
│              ╭───────╮              │
│              │ pez   │              │   ← pez héroe (55mm)
│              │  ΙΧΘΥΣ │              │      con las 5 letras
│              ╰───────╯              │
│                                     │
│                                     │
│      « Donde está tu tesoro,        │   ← lema italic, serif
│       allí estará también           │
│           tu corazón »              │
│                                     │
│                 ◆                   │   ← rombo dorado mínimo
│                                     │
│            Mateo 6,21               │   ← cita small caps
│                                     │
│                                     │
│         4-6 SEPTIEMBRE 2026         │   ← fecha al pie
│                                     │
└─────────────────────────────────────┘
```

**Características:**
- "ETC 88" se reduce a un **LXXXVIII romano** grande sobre el pez (literario, católico, sobrio).
- Pez héroe 55mm centrado, con sombra suave.
- Un solo lema, en serif italic grande, con mucho aire.
- Cita Mt 6,21 separada por un **rombo dorado** mínimo.
- "Siempre amigos" se va a la portadilla interior (donde ya está).
- Marco: un filete dorado al 3% en los 4 lados, a 8mm del borde.

**Tradeoff:** **muy sobria**. Pierde calor y "fiesta eteciana". Pero gana presencia editorial.

---

### 🅱 Opción B — "Iconográfica" (mi favorita)

**Concepto:** el pez es el **único elemento visual**, el "ETC 88" se compone alrededor de él, todo lo demás respira al pie.

```
┌─────────────────────────────────────┐
│                                     │
│   ENCUENTRO TOTAL CON CRISTO        │   ← eyebrow tracking amplio
│   ────────────────────────────      │
│                                     │
│                                     │
│              ╭───────╮              │
│   E T C  ─→  │       │  ←─ 8 8     │   ← pez al centro,
│              │  ΙΧΘΥΣ │              │      letras flanqueando
│              ╰───────╯              │
│                                     │
│                                     │
│     Carpeta del equipo · 2026       │   ← subtítulo + año
│                                     │
│                                     │
│                                     │
│                                     │
│  ┌─────────────────────────────────┐│
│  │                                 ││   ← bloque cita al pie
│  │ « Donde está tu tesoro,         ││      con filete dorado
│  │   allí estará también           ││      izquierdo
│  │   tu corazón »                  ││
│  │                                 ││
│  │            Mateo 6,21           ││
│  └─────────────────────────────────┘│
│                                     │
│        4-6 de septiembre            │
│                                     │
└─────────────────────────────────────┘
```

**Características:**
- **"ETC" a la izquierda + pez al centro + "88" a la derecha** — el pez **literalmente conecta** las letras del nombre del retiro. Da una composición horizontal armónica.
- "ETC" en marrón grande (la tradición eteciana) + "88" en dorado oscuro (el año/edición, no rojo navidad).
- Pez 60mm, héroe.
- Bloque de lema al pie con filete dorado izquierdo — como callout editorial.
- Subtítulo simple: "Carpeta del equipo · 2026" — claro y limpio.
- Fecha simple al pie sin mayúsculas — "4-6 de septiembre".

**Tradeoff:** rompe el patrón clásico de "ETC 88" apilados verticalmente. Pero gana **coherencia visual** (el pez une las letras) y se siente más "editorial moderno".

---

### 🅲 Opción C — "Manuscrita/cálida"

**Concepto:** abraza la **fuente marker** que ya está en los anexos y la trae a la portada. Más calidez, menos editorial.

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│         ENCUENTRO TOTAL              │   ← eyebrow small caps
│            CON CRISTO                │
│                                     │
│                                     │
│      ┌──── ETC 88 ────┐             │   ← marker grande
│      │     ╭─────╮    │             │      con el pez DENTRO
│      │     │ pez │    │             │      del marco del 88
│      │     ╰─────╯    │             │
│      └────────────────┘             │
│                                     │
│         Carpeta del equipo           │   ← italic serif
│                                     │
│                                     │
│   « donde está tu tesoro,           │   ← lema en marker  
│     allí estará también              │      ligero (no serif)
│     tu corazón. »                    │
│                                     │
│           — Mt 6,21 —               │
│                                     │
│                                     │
│      ❤  ❤      Siempre amigos       │   ← 2 corazones DORADOS
│                Jn 15,15              │
│                                     │
│        4-6 sept 2026                 │
└─────────────────────────────────────┘
```

**Características:**
- "ETC 88" en **fuente marker** (la misma que los anexos) — humanidad, no perfección.
- Pez **dentro del marco del 88**, como si el pez fuera el "0" o la unidad visual del número.
- Lema también en marker, ligero — como escrito a mano.
- **"Siempre amigos" SÍ va en portada** en esta opción, en dorado, como firma del libro.
- Corazones en **dorado + dorado oscuro** (no marrón + negro).
- Estética: cuaderno de viaje, no libro editorial.

**Tradeoff:** **menos editorial, más cuaderno**. Funciona si quieres que se sienta "manual del peregrino" en vez de "libro institucional". Es la más arriesgada.

## 3. Mi recomendación final: **Opción B con elementos de A**

### Por qué
- **El pez merece ser héroe** — Opción B lo logra mejor (la composición horizontal lo enmarca).
- **Restamos elementos:** quitamos "Siempre amigos" + 2 corazones de la portada → portadilla interior.
- **El 88 en dorado oscuro** (no rojo navidad) es más eteciano y coherente con el pez.
- **El lema en bloque editorial al pie** con filete dorado da peso espiritual sin saturar visualmente.
- **Subtítulo simple "Carpeta del equipo · 2026"** evita redundancia.

### Especificaciones técnicas exactas

| Elemento | Detalle |
|---|---|
| **Formato** | Media carta (5.5 × 8.5 pulg) o A5 (148 × 210 mm) |
| **Fondo** | Crema `#F4EFE1` con grano sutil al 4% (textura de papel) |
| **Eyebrow** | "ENCUENTRO TOTAL CON CRISTO" — sans uppercase 8.5pt, tracking 0.18em, marrón `#3A2A1A`, centrado, a 25mm del borde superior. Filete fino marrón abajo, 30mm de ancho. |
| **ETC + 88** | "ETC" en serif display peso 700, 64pt, marrón `#3A2A1A`. Pez al centro (55mm). "88" en serif display peso 700, 64pt, dorado oscuro `#B58A2C`. Composición horizontal en la mitad superior, separación pez-letras: 12mm. |
| **Pez ICTUS** | Versión heredada (la original que ya tienes), 55mm de alto, contorno marrón `#3A2A1A` 1.5pt, las 5 letras en sus colores ΙΧΘΥΣ refinados. Sombra suave al 18%. |
| **Subtítulo** | "Carpeta del equipo · 2026" — serif italic, 14pt, marrón al 70%, centrado, 12mm debajo del bloque ETC-pez-88. |
| **Bloque lema** | Cuadro de 95mm de ancho, alto auto. Filete dorado `#B58A2C` izquierdo de 1.5mm. Interior: lema en serif italic 22pt marrón, alineado izquierda. Debajo: cita "Mateo 6,21" en small caps 9pt marrón al 60%, separada por 4mm. Posición: tercio inferior, centrado horizontalmente. |
| **Fecha** | "4-6 de septiembre" — serif italic 12pt marrón al 80%, centrada, a 18mm del borde inferior. Sin año (el año está en el subtítulo). |
| **Marco** | Filete dorado al 5% en los 4 lados, a 8mm del borde físico. Sutil pero anclado. |

### Lo que cambia respecto a la portada actual
1. ❌ Quitas: "Siempre amigos" + 2 corazones (van a portadilla interior).
2. ❌ Quitas: el "Carpeta del equipo" como subtítulo grande arriba (se simplifica al subtítulo nuevo).
3. ✅ Cambias: ETC azul + 88 rojo → **ETC marrón + 88 dorado oscuro**.
4. ✅ Cambias: pez en composición vertical → pez en composición horizontal con ETC y 88 a sus lados.
5. ✅ Agregas: filete dorado izquierdo en el bloque del lema (callout editorial).
6. ✅ Agregas: marco dorado al 5% en bordes (estructura editorial).
7. ✅ Cambias: fecha al pie de mayúsculas → italic cálido.

## 4. Contracubierta — la pareja de la portada

Si la portada hace el trabajo, la contracubierta cierra el círculo:

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│                                     │
│              ╭───────╮              │
│              │ pez   │              │   ← pez héroe (45mm)
│              │  ΙΧΘΥΣ │              │
│              ╰───────╯              │
│                                     │
│                                     │
│         ❤  Siempre amigos  ❤        │   ← lema eteciano
│                                     │      dorado + corazones
│             — Jn 15,15 —            │
│                                     │
│                                     │
│                                     │
│                                     │
│                                     │
│                                     │
│                                     │
│                                     │
│  ─────────────────────────────────  │
│   ASOCIACIÓN ETECIANA               │   ← pie institucional
│   Obra de la Iglesia Católica · 2026│
└─────────────────────────────────────┘
```

**Características:**
- Pez de nuevo (más pequeño que portada — 45mm), centrado en el tercio superior.
- "Siempre amigos" como lema eteciano (aquí sí, no en portada) + cita Jn 15,15.
- 2 corazones DORADOS flanqueando el lema.
- Pie institucional sobrio: "Asociación Eteciana · Obra de la Iglesia Católica · 2026".
- Mismo marco dorado al 5% que portada.

Composición simétrica con la portada: la portada anuncia, la contracubierta firma.
