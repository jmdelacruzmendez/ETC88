## 4. Flujo de seguimiento (no se pierde ningún hilo)
> Cada carta enviada se registra en una hoja. Idealmente la administra Finanzas/Tesorería junto con Recaudación.

| Campo | Por qué |
|---|---|
| Fecha de envío | mide tiempo de respuesta |
| Destinatario / contacto / teléfono | trazabilidad |
| Plantilla usada (A/B/C) | mantener tono coherente |
| Qué se pidió | comparar con lo recibido |
| Quién hizo el primer contacto | dueño del seguimiento |
| Estado | enviada · acusada · negociando · confirmada · entregada · declinada |
| Fecha próxima acción | recordatorio (call/visita/recoger) |
| Monto / unidades comprometidas | input al flujo de caja |
| Monto / unidades recibidas | reconciliación |
| Constancia firmada (sí/no) | obligatoria — la firma Co-Dir |

**Cadencia:**
- **Día 0:** envío de la carta (correo o WhatsApp con PDF).
- **Día 3:** llamada de seguimiento si no acusó recibo.
- **Día 7:** visita en persona si el monto/relación lo justifica.
- **Cada lunes:** Recaudación reporta a Co-Dir el estado de cada hilo abierto.

## 5. Reglas de oro (para no quemar contactos)
1. **Cada carta personalizada:** Razón social correcta · nombre del contacto · monto/rubro específico. Nada genérico.
2. **No spam masivo:** una carta = una conversación. Nunca enviar la misma carta a 30 destinatarios.
3. **Una sola persona por hilo:** quien envía la carta es quien la sigue (evita que el destinatario reciba mensajes cruzados).
4. **Constancia siempre:** todo donante recibe constancia firmada por la Dirección (es lo que distingue al ETC de una colecta informal).
5. **Confidencialidad:** no se mencionan donantes pasados sin su permiso.
6. **El director firma. Recaudación redacta.** Sin la firma de Co-Dir no sale carta.
